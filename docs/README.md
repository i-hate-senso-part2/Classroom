The repository map accounts for the application source, static browser assets, package/configuration files, deployment files, and project metadata. Dependency contents and vendored/generated runtime bundles are documented as grouped assets rather than copied into separate descriptions for every upstream file. Update the relevant page when behavior or configuration changes.
